# 문체 가이드 (MJC in one)

## 목표

앱에서 사용자에게 노출되는 문장 표현을 일관되게 유지합니다.

## 기본 규칙

- 앱에 노출되는 **문장**은 `~습니다.` / `~입니다.`로 끝냅니다.
- **질문형**은 `~습니까?`로 끝냅니다.
- 사용자 **행동 요청**은 `~해 주세요.`로 통일합니다. (`해주세요`는 지양합니다)
- **반말/해요체/다체**를 섞어 쓰지 않습니다.

## 권장 템플릿

### 오류/시스템 메시지

- “요청을 처리할 수 없습니다. 잠시 후 다시 시도해 주세요.”
- “인터넷 연결이 필요합니다. 네트워크 상태를 확인해 주세요.”
- “권한이 필요합니다. 설정에서 권한을 허용해 주세요.”

### 빈 화면(Empty state)

- “표시할 항목이 없습니다.”
- “등록된 항목이 없습니다.”
- (필요 시) “새로고침해 주세요.”

## 라벨 규칙(버튼/메뉴)

- 버튼/탭/메뉴 라벨은 문장으로 쓰지 않습니다.
- 짧은 명사형/동사형으로 통일합니다. 예: “확인”, “닫기”, “저장”, “새로고침”, “재시도”

## 금지/주의

- 사용자를 탓하는 표현(예: “잘못 입력했습니다”) 대신 중립 표현을 사용합니다.
  - 예: “입력값을 확인해 주세요.”
